                            TECHNICAL SUMMARY
================================================================================

PLATFORM ARCHITECTURE:
├─ Hardware: NVIDIA Hopper/Blackwell GPUs in confidential computing mode
├─ Security: Trusted Execution Environment (TEE) with cryptographic attestation
├─ Routing: Router enclaves for load balancing and verification
├─ API: OpenAI-compatible REST API with SDK support
└─ Encryption: End-to-end encryption, decryption only inside enclave

AUTHENTICATION:
├─ Method: Bearer token (API key) in Authorization header
├─ Format: Authorization: Bearer sk-xxxx...
├─ Key generation: https://dash.tinfoil.sh
├─ Environment variable: TINFOIL_API_KEY
└─ Security: SDK handles certificate pinning and attestation verification

API COMPATIBILITY:
├─ Format: OpenAI /v1/chat/completions compatible
├─ Request: Standard JSON chat completion format
├─ Response: Standard OpenAI response format with token usage
├─ Tool calling: Standard function calling pattern
└─ Streaming: Supported via stream=true parameter

SECURITY GUARANTEES:
├─ Hardware isolation: Dedicated GPUs in secure enclaves

                            IMPLEMENTATION SNAPSHOT
================================================================================

SETUP TIME: ~15-20 minutes
1. Generate API key at https://dash.tinfoil.sh (5 min)
2. Install Python SDK: pip install tinfoil (2 min)
3. Set environment variable: export TINFOIL_API_KEY=sk-... (1 min)
4. Test basic chat request (5 min)
5. Verify billing/usage dashboard (2 min)

BASIC CODE PATTERN:
```python
from tinfoil import TinfoilAI

client = TinfoilAI()  # auto-loads TINFOIL_API_KEY env var

response = client.chat.completions.create(
    model="kimi-k2.5",
    messages=[{"role": "user", "content": "Hello"}]
)

print(response.choices[0].message.content)
```

TOOL CALLING PATTERN:
```python
response = client.chat.completions.create(
    model="kimi-k2.5",
    messages=[...],
    tools=[{
        "type": "function",
        "function": {
            "name": "get_weather",
            "description": "Get weather for a location",
            "parameters": {
                "type": "object",
                "properties": {"city": {"type": "string"}},
                "required": ["city"]
            }
        }
    }],
    tool_choice="auto"
)
```

AUTHENTICATION PATTERN:
POST https://inference.tinfoil.sh/v1/chat/completions
Authorization: Bearer sk-your-api-key
Content-Type: application/json

{
  "model": "kimi-k2.5",
  "messages": [...],
  "tools": [...] (optional)
}

├─ Privacy: Tinfoil (hardware-verified), Claude (trust-based)
