### Critical Gaps TrustMesh Can Fill

1. **No standards-based agent identity at federation boundaries** (DIDs/VCs)
2. **No cryptographically enforced multi-hop audit trails** (immutable, verifiable)
3. **No trust tier system in agent authorization** (private/internal/public)
4. **No pool-based federation** (trusted groups without public registry)
5. **No vault-grade encryption for agent data** (per-capsule, at-rest)
6. **No defense against supply chain attacks on tools** (43 vulnerabilities found)
7. **No rate limiting for multi-agent exfiltration** (bulk data theft prevention)
8. **No soft-leak prevention at federation boundaries** (prevent name/structure leakage)
